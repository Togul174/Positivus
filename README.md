Адаптивный анимированный лендинг сайта Positivus.

Использованные технологии:
1. Webpack - сборщик
2. Sass/SCSS - препроцессор для стилей
3. sass-loader - компилятор css в scss
4. HtmlWebpackPlugin - генерация многостраничности
5. MiniCssExtractPlugin - вынос css в отдельные файлы
6. CopyWebpackPlugin - копирование изображений
7. webpack-dev-server - локальный сервер

запуск локально:
1. установить зависимости - npm i
2. запуск сервера - npm run start
